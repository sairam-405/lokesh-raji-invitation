# Lokesh & Raji - Wedding Invite (React + Vite + React Router)

    npm install
    npm run dev      # http://localhost:5173
    npm run build    # output in dist/

Routes
  /        Welcome page (dark bridge -> tap -> lights on + floating button)
  /invite  Invitation page (names, families, scratch card, countdown, venue)

Deploy on Vercel: vercel.json already rewrites all paths to index.html.
Add your images/audio under public/ (see public/README.txt).
